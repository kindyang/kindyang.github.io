## Part 3 · 关键字段深挖 ★

### 3.1 `ViolationYear` vs `DeclareDate` —— 本项目最关键的理解点

| 字段 | 含义 | 打标签应该用 |
|---|---|---|
| `ViolationYear` | 违规**实际发生**的年份 | ✅ **用这个** |
| `DeclareDate` | 处罚**公告发布**的日期 | ❌ 不能用 |

**本次实测滞后分布**（基于 13,418 条单一年份记录，全部可解析）：

| 指标 | 数值 |
|---|---|
| 滞后均值 | **0.94 年** |
| 滞后中位数 | **1 年** |
| 滞后 ≥ 2 年占比 | **19.3%** |
| 负滞后（公告早于违规年） | 0 条 |

| 年差 | 0 | 1 | 2 | 3 | 4 | 5+ |
|---|---|---|---|---|---|---|
| 记录数 | 6,574 | 4,255 | 1,183 | 608 | 336 | 462 |

**为什么不能用 DeclareDate**：

```
记录: Symbol=000002 类似情况, ViolationYear=2015, DeclareDate=2016-07-21
该公司 2015 年舞弊，2016 年被公告处罚。
若用 DeclareDate 打标签 → 标签打在 2016 年 → 2016 年（舞弊败露后业绩崩塌）的财务数据
被用来"预测"2016 年舞弊 → 模型学到的是"败露后的表现"，而不是"舞弊前的征兆"
→ 典型的【用结果预测结果】
```

### 3.4 ★ `Accper = 01-01` 是「年初数」，与上年 12-31 重复（本次新发现）

实测 `Typrep × 月日` 交叉表（资产负债表）：

```
T=A  01-01  77,435 (11.02%)     T=B  01-01  71,840 (10.22%)
T=A  03-31  75,240 (10.71%)     T=B  03-31  48,811 ( 6.95%)
T=A  06-30  83,692 (11.91%)     T=B  06-30  73,378 (10.44%)
T=A  09-30  71,906 (10.23%)     T=B  09-30  46,373 ( 6.60%)
T=A  12-31  81,837 (11.65%)     T=B  12-31  72,162 (10.27%)
```

**单个公司时间轴实证**（`000001 深发展A`，资产负债表 `A001000000` 资产总计）：

| Accper | 资产总计 | 与上一年 12-31 比较 |
|---|---|---|
| 1998-12-31 | 39,399,858,617 | — |
| 1999-01-01 | 39,008,042,523 | DIFF（更正后数值） |
| 2001-12-31 | 120,126,983,351 | — |
| **2002-01-01** | **120,126,983,351** | **SAME（完全相同）** |
| 2004-01-01 | 193,453,415,330 | DIFF（上年度 192,851,003,723） |
| 2006-01-01 | 222,324,686,641 | DIFF；`IfCorrect=1`，`DeclareDate=2008-03-20` |

**结论**：`Accper=01-01` 记录是「**上年 12-31 的年初数副本**」，大多数与上年年报数值相同，
少数为差错更正后的数值（多与 `IfCorrect=1` 同时出现）。

**后果**：若不过滤，
1. 每个公司-年多出一条**重复的年度记录**（虚增样本量，年度面板会被重复计数）；
2. 一部分 `01-01` 行携带的是**更正后（事后）数值** → 直接构成时间泄漏。

**规避**：年报筛选严格用 `Accper[5:10] == "12-31"`。

### 4.1 关联键确认（实测）

| 项 | 违规处罚表 `Symbol` | 财务两表 `Stkcd` |
|---|---|---|
| 编码形式 | 6 位字符（`000002`） | 6 位字符（`000001`） |
| 唯一值数 | **3,937**（剔除 2 条残留后） | **6,001**（两表完全一致） |
| 前导零 | 9,894 条记录 | 1,642 个代码 |
| **交集** | — | **3,937 = 违规表代码 100% 命中财务表** ✅ |

**结论：`Symbol` = `Stkcd`，可直接等值连接；违规表全部代码都能在财务表中找到。**
反向：财务表有 2,064 个代码在违规表中从未出现（=天然负样本来源，符合预期）。

> 两表代码均为字符串，**必须 `astype(str).str.zfill(6)`**，否则前导零丢失。

### 4.2 关联结构

```
                    ┌─────────────────────┐
                    │  违规处罚表          │
                    │  STK_Violation_Main │
                    │  22,950 条           │
                    │  粒度: 一次处罚事件   │
                    └──────────┬──────────┘
                               │ Symbol + ViolationYear（年-编码段位配对）
                               │ ↓ 聚合为公司-年度标签
                    ┌──────────▼──────────┐
                    │  fraud_label         │
                    │  粒度: 公司 × 年     │  实测 V1 = 10,603 公司-年
                    │  Stkcd, Year         │
                    └──────────┬──────────┘
                               │ Stkcd + Year（left join！）
        ┌──────────────────────┴──────────────────────┐
        │                                              │
┌───────▼────────┐                          ┌─────────▼──────┐
│  资产负债表     │  ←─ Stkcd+Accper+Typrep →│   利润表        │
│  FS_Combas     │      横向合并             │   FS_Comins    │
│  702,674 行     │                          │  704,369 行     │
└────────────────┘                          └────────────────┘
   ↓ 年报筛选: Typrep=A & Accper=12-31  →  81,837 行 / 81,837 行
```

### 4.3 主键定义

| 表 | 主键 | 实测说明 |
|---|---|---|
| 违规处罚表 | `ViolationID` | 单条处罚事件唯一 |
| 资产负债表 | `Stkcd` + `Accper` + `Typrep` | 实测 `(Stkcd,Accper)` 重复 313,262 → **A/B 两种报表各一行**，三键才唯一 |
| 利润表 | `Stkcd` + `Accper` + `Typrep` | 同上（重复 312,310） |
| **最终面板** | **`Stkcd` + `Year`** | 筛掉 Typrep=B 与非 12-31 后，一家公司一年一行 |

### 4.4 Merge 具体代码

```python
import pandas as pd

# ── Step 1: 两张财务表横向合并（三键都要，否则 A/B 报表会错配）──
fin = pd.merge(combas, comins,
               on=["Stkcd", "Accper", "Typrep"],
               how="outer",
               suffixes=("", "_dup"))     # 两表都有 ShortName/IfCorrect/DeclareDate！
fin = fin[fin["Typrep"] == "A"]
fin = fin[fin["Accper"].str[5:10] == "12-31"]
fin["Year"] = fin["Accper"].str[:4].astype(int)

# ── Step 2: 财务表 ← 舞弊标签（★★ 必须 left join ★★）──
panel = pd.merge(fin, label, on=["Stkcd", "Year"], how="left")
panel["is_fraud"] = panel["is_fraud"].fillna(0).astype(int)
```

### 4.5 为什么财务表 merge 标签必须 left join

用 inner join 会把"未舞弊的公司-年"全部丢掉，剩下 100% 正样本，模型学不到任何区分能力。

**自检**（每次 merge 后必做）：

```python
rate = panel["is_fraud"].mean()
assert rate < 0.99, f"舞弊率 {rate:.2%} = 100%！用了 inner join，立即回退"
# 参考区间（本次实测）：2007-2021 ≈ 15%，全区间 ≈ 13%
```

### 陷阱 2 · 三张 xlsx 内部维度声明全部有误 + 大表读取 ⭐⭐

**实测**：三张表的 `<dimension>` 都只声明第 1 列：

| 文件 | 声明 dimension | 真实形状 |
|---|---|---|
| `STK_Violation_Main.xlsx` | `A1:A22953` | 22,953 × 21 |
| `FS_Comins.xlsx` | `A1:A704372` | 704,372 × 81 |
| `FS_Combas.xlsx` | `A1:A702677` | 702,677 × 154 |

**后果**：`openpyxl` read_only 模式若**不重置维度，每行只能读出 1 个值**（shape 退化成 (N,1)）。

**规避（本项目已验证可用的两条路）**：

```python
# 方案 A（推荐，本次探索采用）：read_only + 重置维度，流式逐行
from openpyxl import load_workbook
wb = load_workbook(path, read_only=True)
ws = wb.worksheets[0]
ws.reset_dimensions()          # ★ 关键：一行代码修复维度 bug
for row in ws.iter_rows(values_only=True):
    ...                        # row 是完整 81/154 元组

# 方案 B：只读需要的列（省内存、更快）
ws.reset_dimensions()
for row in ws.iter_rows(min_col=1, max_col=4, values_only=True):
    ...
```

**实测耗时**（本机）：

| 操作 | 耗时 |
|---|---|
| `FS_Comins` 全列（81 列）流式扫描 704,372 行 | **315 秒** |
| `FS_Combas` 全列（154 列）流式扫描 702,677 行 | **587 秒** |
| 限定 4 列扫描同文件 | 约 1/3 时间 |

> 📌 用 `pd.read_excel(usecols=[...])` 也可以，但 pandas 仍会解析全表；**且实测在本文件上会把 `Accper` 推断成 float、`Stkcd` 丢前导零**。因此本项目统一走 openpyxl 流式 + `dtype=str`。

### 陷阱 4 · `ViolationYear` 与 `ViolationTypeID` 是"位置配对"的多值字段 ⭐⭐

**实测**：全表 **7,649 条**（33.3%）的 `ViolationYear` 含 `;` 多年份；`IsViolated=Y` 后为 **5,228 条**。

**关键结构**：

```
ViolationYear    = "2010;2011;2012"
ViolationTypeID  = "P2515;P2515;P2503"
                    ↑2010  ↑2011   ↑2012
两个字段按 ';' 分段、位置一一对应：
  2010 → P2515（一般会计处理不当，不是舞弊）
  2011 → P2515（同上）
  2012 → P2503（虚假记载，是舞弊）
同一"年段内"还可能用顿号(、)并列多个类型：
  ViolationYear="2008;2009", ViolationTypeID="P2599;P2503、P2599"
  → 2008年=P2599；2009年=P2503 和 P2599 两种
年份段可能是 N/A（未披露，实测 1,180 行；Y 类 1,053 行），必须丢弃。
```

**实测验证**：全表 7,649 条多年份记录，`ViolationYear` 段数与 `ViolationTypeID` 段数 **100% 相等**（7,649/7,649）——位置配对成立的硬证据。

**错误做法**（都会产生系统性标签错误）：

```python
# ❌ 错法一：把记录里所有年份都打上标签 → 2010/2011 被误标
# ❌ 错法二：先整行筛掉非舞弊记录再展开所有年份 → 混合记录的非舞弊年份全部误标
```

**正确做法**（先分段配对，再逐年判断该段是否命中舞弊码）：

```python
FRAUD = {"P2501","P2502","P2503","P2504","P2505","P2506"}

def parse_pairs(vy, vt):
    ys, ts = str(vy).split(";"), str(vt).split(";")
    if len(ys) != len(ts):                 # 实测未出现，保守跳过
        return []
    out = []
    for y, t in zip(ys, ts):
        y = y.strip()
        if not (y.isdigit() and len(y) == 4):    # N/A、空 直接跳过
            continue
        codes = {c.strip() for c in t.replace("、", ";").split(";") if c.strip()}
        out.append((int(y), codes))
    return out

for year, codes in parse_pairs(r.ViolationYear, r.ViolationTypeID):
    if codes & FRAUD:
        label(Stkcd, year, is_fraud=1)
```

## 附录 · 标准读取代码（本项目实测可用）

```python
import pandas as pd
from openpyxl import load_workbook

def stream_sheet(path, cols=None):
    """流式读取 CSMAR 大表（自动修复维度 bug）。cols=None 读全列。"""
    wb = load_workbook(path, read_only=True)
    ws = wb.worksheets[0]
    ws.reset_dimensions()                      # ★ 修复 A1:Axxxxx 维度 bug
    it = (ws.iter_rows(min_col=1, max_col=cols, values_only=True) if cols
          else ws.iter_rows(values_only=True))
    for row in it:
        yield row
    wb.close()

def read_violation(path):
    """违规表：小表，pandas 直读 + 过滤残留行"""
    df = pd.read_excel(path, dtype=str)
    df = df[df["Symbol"].astype(str).str.match(r"^\d{6}$", na=False)].copy()
    df["Symbol"] = df["Symbol"].astype(str).str.zfill(6)
    return df.reset_index(drop=True)

def read_fin_annual(path, key_cols, business_cols):
    """财务表：流式读 → 三行表头丢弃 → 只留年报（A + 12-31）"""
    rows, hdr = [], None
    for i, row in enumerate(stream_sheet(path)):
        if i == 0:
            hdr = [str(x).strip() if x is not None else "" for x in row]
            idx = {n: j for j, n in enumerate(hdr)}
            continue
        if i < 3:
            continue
        c0 = row[0]
        if not (isinstance(c0, str) and len(c0) == 6 and c0.isdigit()):
            continue
        accper = str(row[idx["Accper"]])
        if row[idx["Typrep"]] != "A" or accper[5:10] != "12-31":
            continue
        rows.append(tuple(row[idx[c]] for c in key_cols + business_cols))
    return pd.DataFrame(rows, columns=key_cols + business_cols)
```
