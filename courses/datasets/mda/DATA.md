- **覆盖**：2018–2022 共 5 个年度，每年一个独立文件夹，结构完全一致。
- **内容**：中国 A 股上市公司定期报告中的"管理层讨论与分析（MD&A）"文本及其量化指标。

## 3. 表格字段含义（xlsx，9 列）

对照 `管理层讨论与分析_字段说明.txt`（列出 10 个字段，其中 **BusDA 未出现在表格中**）：

| 列名 | 含义 | 说明 |
|------|------|------|
| Scode | 股票代码 | 6 位字符串，保留前导零（如 `000001`） |
| Coname | 公司简称 | |

| Anatime | 经营分析时间（发布时间） | 实际为**报告期日期**，每年仅 `YYYY-06-30`（半年报）/`YYYY-12-31`（年报）两种 |

## 4. 主键与表格↔文本关联

- **表格主键 = `(Scode, Anatime)`**（股票代码 + 报告期）。
  - `Scode` 单独不唯一：约 47% 公司每年有 2 行（半年报 + 年报）。
  - `(Scode, Year)` 也不唯一，**必须带 Anatime**。
  - 全表无整行重复、无缺失值。
- **关联键**：表格 `Scode` + `Anatime` ↔ 文本文件名 `{Scode}_{Anatime}.txt`。
  - 例：`Scode=000001, Anatime=2018-12-31` ↔ `文本/000001_2018-12-31.txt`。
  - 文件名日期与 `Anatime` 逐字符一致，可直接用字符串拼接做 join。
  - 所有 txt 文件在表格中都有对应行（文件级匹配 100%），反之不成立（见下）。

## 5. 数据质量陷阱（务必注意）

1. **xlsx 首行是中文标签行，不是数据**。用 pandas 直接 `read_excel` 后，第 1 行数据会是 `股票代码 / 公司简称 / 会计年度 …` 的字段中文名，**需剔除**（按 `Scode != '股票代码'` 或 `skiprows=[1]`）。剔除后各年行数见第 1 节表。
2. **文本只覆盖年报（12-31），半年报（06-30）整体无全文**。
   - 2019–2022：`文本/` 仅含年报，半年报行（3,444 / 3,835 / 4,063 / 4,416 行）**没有对应 txt**。
   - 2018 例外：除 3,585 份年报外，另有 **85 份半年报** 文本。
   - 结论：做文本分析时样本量骤减，约 4.7 万行表格中仅约 25,408 行能拿到全文；用文本变量务必先按 `Anatime` 过滤为年报。
3. **`文本/` 目录混入非文本垃圾文件**（2018 / 2020 / 2022 年份最末尾）：`数据来源.pdf` 与 3 个 `草莓科研*.png` 水印图。遍历目录时**必须按 `.txt` 后缀过滤**（2019 / 2021 年份无此问题）。
4. **字段说明与表格列不一致**：说明 txt 列出 10 个字段含 `BusDA`（全文），但表格实际只有 9 列，`BusDA` 内容在 `文本/` 中，不要指望从表格取全文。
5. **编码**：`文本/*.txt` 为 **UTF-8 无 BOM**（抽样 10 个文件均如此）；`字段说明.txt` 为 **UTF-8 带 BOM**（读取建议 `encoding='utf-8-sig'`）。中文 Windows 下勿用默认 gbk 打开。
6. **`Anatime` 是字符串日期**，形如 `2018-12-31`（长度固定 10），不是时间戳；`Year` 亦以字符串形式读入，注意类型转换。
7. **文本无标题/无结构化标签**：txt 以正文开头（2018/2019 多起于"经营情况讨论与分析"，2021/2022 多起于"管理层讨论与分析…"），版式逐年变化；抽取具体段落需自行按关键词/章节号定位。
8. **数值列口径未知**：`Posvocnum / Negvocnum / Sentnum / Charnum / WordNum` 的计数规则（词表、分词工具）未在说明中给出，跨年份/跨研究对比时需谨慎。

## 6. 快速上手代码

```python
import os, re
import pandas as pd

ROOT = r"数据集/MD&A/MD&A 2"
year = "2022"

# 1) 读表并剔除中文标签行
df = pd.read_excel(os.path.join(ROOT, year, f"管理层讨论与分析_{year}.xlsx"),
                   sheet_name="Sheet0", dtype=str)
df = df[df["Scode"].str.strip() != "股票代码"].reset_index(drop=True)
num_cols = ["Posvocnum", "Negvocnum", "Sentnum", "Charnum", "WordNum"]
df[num_cols] = df[num_cols].apply(pd.to_numeric)

# 2) 只保留有全文的年报
df = df[df["Anatime"].str.endswith("-12-31")].copy()

# 3) 关联文本（文件名 = Scode_Anatime.txt）
txtdir = os.path.join(ROOT, year, "文本")
df["path"] = df.apply(lambda r: os.path.join(txtdir, f"{r['Scode']}_{r['Anatime']}.txt"), axis=1)
df["text"] = df["path"].map(lambda p: open(p, encoding="utf-8").read() if os.path.exists(p) else None)
```
